# Dictionary illustrations

## Abscissa

`abscissa.png` is the coordinate diagram from _Webster's International Dictionary_ (1907), printed page 7, [Internet Archive scan n112](https://archive.org/download/webstersinternat01webs/page/n112.jpg?scale=1).

The 156 × 129 pixel image is an unchanged crop of the 2399 × 3371 pixel scan, bounded by (646, 1577) and (802, 1706). O is the origin. X and Y mark the horizontal and vertical projections of P.
